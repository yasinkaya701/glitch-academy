# Premium lab surface materials

`blue_titanium.tres` is the shared satin-blue panel material used by the 3D experiment platform.

- `blue_titanium_albedo_4k.jpg`: 4096 × 4096 generated panel atlas.
- `blue_titanium_normal_4k.png`: 4096 × 4096 subtle tangent-space normal derived from the panel relief.
- `blue_titanium_roughness_4k.png`: 4096 × 4096 satin-finish roughness map.
- `blue_titanium_source.png`: original 1254 × 1254 generated source artwork.

The source artwork was generated for this project with OpenAI ImageGen. The 4K files are Lanczos-resampled from that source; their dimensions do not imply additional source detail. The normal and roughness maps were derived for this material from the generated panel artwork.
