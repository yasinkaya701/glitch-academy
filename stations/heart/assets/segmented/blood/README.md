# Kan varlıkları

`red_blood_cell.glb` iki yüzü çukur, yumuşak kenarlı eritrosit modelidir. `anatomy_util.gd` bunu kalp içi ve damar akışı boyunca çoklu örnekler olarak yönlendirir; hücreler akış doğrultusuna döner. Eğitim görünümünde oksijence zengin kan canlı kırmızı, oksijence fakir kan koyu bordo görünür.
