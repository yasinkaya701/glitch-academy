# Blood sprites

`rbc_rich.png` and `rbc_poor.png` are 128 × 128 RGBA cutouts. They depict the same biconcave erythrocyte geometry with oxygen-rich coral highlights and a darker, cooler deoxygenated palette. `rbc_sheet.png` is a horizontal eight-frame, 1024 × 128 tumble loop (each frame is 128 × 128); the frames flatten through an edge-on pose to imply rotation in the particle plane. Editable sources are the same-named SVG files. There are no labels or external imagery.
