# Vektör Limanı assets

All state sprites share a centered 512×512 transparent canvas. At the same render scale, the capsule occupies about 20% of the dock ring's outer diameter; `capsule_top.png` and `capsule_thrust.png` are aligned state variants. The earlier full-size variants are preserved in `archive/`.

`harbor_top.png` is the 2048×1536 playfield. `wrong_dock_wreck.png` is a 1024×1024 transparent failed-approach sprite.

`harbor_fault.png` is deferred: the previous cinematic render is preserved as `archive/harbor_fault_v1_archived.png`. It did not match the top-down harbor's visual language closely enough to ship as an opening frame.
