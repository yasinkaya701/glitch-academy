# Font asset note

The local system has no bundled OFL family containing a complete Latin Extended set and a mono companion, and the installed system fonts are not redistributable. Font binaries were not copied. Recommended family for integration: IBM Plex Sans (headings/body) and IBM Plex Mono (formulas), both under the SIL Open Font License; obtain from the official Google Fonts repository and include its OFL.txt when font files can be added.

Turkish coverage required: İ, ı, Ş, Ğ, Ç, Ö, Ü.
